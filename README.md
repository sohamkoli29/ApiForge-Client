# API Testing Tool

A full-stack API testing tool similar to Postman, built with React + Vite frontend and Node.js + Express backend, using Convex for database.

## Features
- Send API requests (GET, POST, PUT, DELETE, PATCH)
- Add headers, params, and request body
- View response status, headers, and body
- Save request history
- Organize APIs in collections
- User authentication

## Tech Stack
- **Frontend**: React + Vite, Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: Convex
- **Deployment**: Vercel (frontend), Railway (backend)
